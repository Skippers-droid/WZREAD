# WZREAD

A cross-platform reader application.

Discover and read manga, webtoons, and comics on all your devices with just one click.

## Downloads

WZREAD is currently in development, with a stable release expected in September.

## Expected Features
Local reading
Categories to organize your library (tags)
Tracker support
Backups
Cross-platform support
Configurable settings, including multiple viewers, reading directions, and more
Demo

# About

This project is inspired by the Mihon
 project, Kotatsu
, and many others.

I don't expect this project to become popular, as it is primarily a personal project to improve my skills with Rust.

WZREAD follows an source → extension  → base architecture. The reader comes with a default source installed, but you can choose which extensions you want to use.

> Security Warning: Do not use extensions from sources you don't know or trust. Extensions have access to the application and could potentially steal your credentials or other sensitive information. Only install extensions if you have reviewed and trust their source code.

The source installed is https://github.com/Skippers-droid/wzread-extensions
